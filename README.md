# highlands_coffee_clone
**_Highlands Coffee Clone_** by **_willbe (Tien Nguyen)_**

## What This Project Includes

- **Framework**: MVC PHP (Zend/Laminas).
- **Frontend**: Bootstrap 5, jQuery, Popper.js, AJAX, fully responsive UI.
- **Internationalization**: Multi-language support using language key files (en.php).
- **Authentication**: Login, registration, user authentication, access control.
- **Admin Panel**: Manage products, categories, users, orders, and reviews.
- **Dynamic UI**: Dynamic dropdowns, per-row pagination, modern layouts, interactive effects.
- **Cart & Order**: Shopping cart, order placement, customer validation, AJAX-based order processing.
- **Review System**: Only allows reviews for logged-in users who have purchased, validated via AJAX.
- **Database**: Doctrine DBAL, MySQL, optimized queries.
- **Docker**: Dockerfile and docker-compose for development and production environments.
- **Documentation**: README, SMTP setup guide, copyright, environment configuration.
- **Version Control**: Git, CI/CD configuration, renovate.json for automated dependency updates.
